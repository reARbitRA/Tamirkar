## آنچه هنوز مانع لانچ عمومی است

1. **تأیید حقوقی** — `docs/legal/*` پیش‌نویس داخلی است و هیچ‌کدام تاریخ و امضا ندارد.
2. **پشتیبان‌گیری و بازیابی** — `scripts/backup-database.sh` و `scripts/restore-database.sh`
   نوشته شده‌اند، اما هنوز دراین محیط اجرا نشده‌اند (postgresql-client در دسترس نبود).
   آزمون بازیابی واقعی و ثبت RPO/RTO باقی است.
3. **CI اندروید** — تاریخچهٔ workflowها کاملاً قرمز است. workflow سرور
   (`.github/workflows/server.yml`) اضافه شد و مسیر پول را پوشش می‌دهد، اما build اندروید
   هنوز در این sandbox قابل اجرا نیست (JDK و Android SDK نصب نیست).
4. **دستگاه و پاسپورت** — API سمت سرور برای `devices` وجود ندارد.
