## آنچه هنوز مانع لانچ عمومی است

1. **تأیید حقوقی** — `docs/legal/*` پیش‌نویس داخلی است و هیچ‌کدام تاریخ و امضا ندارد.
   نیازمند وکیل و شخصیت حقوقی ثبت‌شده. این کار هفته‌ها زمان می‌برد، نه ساعت.

2. **پشتیبان‌گیری و بازیابی** — `scripts/backup-database.sh` و `scripts/restore-database.sh`
   نوشته شده‌اند، اما در این محیط اجرا نشده‌اند چون `pg_dump`/`pg_restore` نصب نبود.
   **عمداً با یک مکانیزم جایگزین «تست» نشد:** ساختن پشتیبان با `COPY` در حالی که production از
   `pg_dump --format=custom` استفاده می‌کند، تأیید مکانیزم اشتباه بود. آزمون بازیابی واقعی و
   ثبت RPO/RTO باقی است.

3. **CI** — `git push` برای `.github/workflows/` رد شد:
   *«refusing to allow a GitHub App to create or update workflow … without `workflows` permission»*.
   workflow آماده در **`ci/proposed/server.yml`** است، نه در `.github/workflows/`.
   یک maintainer باید یک `cp` و یک commit انجام دهد (دستور در `ci/proposed/README.md`).
   `gh run list` هنوز سه run آخر را `completed failure` نشان می‌دهد.
   **این پربازده‌ترین اقدام باقی‌مانده است: ~۱۰ دقیقه برای +۵.۷۸ امتیاز**، چون سقف سختِ ۳۰ روی
   بُعد D5 را برمی‌دارد.

4. **پرداخت زرین‌پال** — `sandbox.zarinpal.com` از این sandbox قابل دسترسی نیست، پس گرفتن
   پرداخت و تقسیم ۸۵/۱۵ اجرا نشده. harness اکنون آماده است:
   `AUDIT_ZARINPAL_MERCHANT_ID=<sandbox-id> node audit/harness/e2e.mjs`
   → J5 به `VERIFIED_WORKING` می‌رسد (**+۲.۷۹ امتیاز**).

5. **کامپایل اندروید** — JDK و Android SDK در این محیط نصب نیست، پس هیچ ادعایی دربارهٔ کد
   Kotlin اجرا نشده. تست مخربِ قبلی بازنویسی و با `grep` تأیید شد، نه با کامپایلر.
