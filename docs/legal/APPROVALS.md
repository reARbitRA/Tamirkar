# ماتریس تأییدهای لازم برای لانچ عمومی

این فایل کد قابل‌اجرا نیست و تیک آن نباید بدون نام، تاریخ و مدرک انجام شود.

- [ ] مشاور حقوقی: حریم خصوصی، شرایط استفاده، لغو/بازپرداخت و ضمانت.
- [ ] مالی: ساختار تسویه، نگه‌داشت وجه، reconciliation و مالک هر حساب ledger.
- [ ] درگاه: قرارداد/مرچنت زرین‌پال، callback HTTPS، sandbox proof و مسیر پشتیبانی.
- [ ] عملیات: ساعات پشتیبانی، مالک KYC، مسئول اختلاف، on-call و kill switches.
- [ ] امنیت: secret manager، TLS، backup/restore drill، rate limiting و لاگ‌گذاری ایمن.
- [ ] محصول: متن‌های فعال با feature flag و عدم نمایش ادعای قابلیت غیرفعال.
