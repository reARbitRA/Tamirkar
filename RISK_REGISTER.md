# Oosta risk register

Scales: likelihood (L) and impact (I) are 1–5. Score = L × I. Current controls describe what is present in this repository, not desired state.

> **Re-scored 2026-10-02** against the current tree. Rows 1, 2, 3, 5, 6 and 7 described a client-only
demo that no longer exists: the server boundary in `services/auth-api` now owns auth, the ledger,
escrow and KYC. Their likelihood was lowered accordingly and each control cell now names the code
that implements it. Rows 8, 13 and 15 keep their score with an explicit **Still open** clause.
